# خطوط مؤقتة

خطوط مفتوحة الرخصة (SIL OFL 1.1) تُستخدم لتنسيق صفحات الدليل إلى أن يُعتمد القسم 5 (الخطوط).
الخط النهائي يُحفظ في `fonts/` مع رخصته، ويُحذف هذا المجلد إن لم يقع الاختيار عليه.

| الخط | الاستخدام المؤقت | الرخصة |
|---|---|---|
| Amiri | العناوين | OFL-Amiri.txt |
| Noto Naskh Arabic | النصوص | OFL-NotoNaskhArabic.txt |
